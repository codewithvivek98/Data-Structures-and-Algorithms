Moore's Voting Algorithm

• Used to find the Majority Element.
• Majority Element appears more than n/2 times.
• Maintains:
  - ans  : current candidate
  - freq : vote count

Algorithm:
1. If freq becomes 0, choose the current element as the new candidate.
2. If current element equals the candidate, increment freq.
3. Otherwise, decrement freq.
4. At the end, the candidate is the majority element (if one is guaranteed to exist).

Time Complexity : O(n)
Space Complexity: O(1)


INPUT;
nums = {2,2,1,1,1,2,2}

DRY RUN
| i | nums[i] | ans | freq |
| - | ------- | --- | ---- |
| 0 | 2       | 2   | 1    |
| 1 | 2       | 2   | 2    |
| 2 | 1       | 2   | 1    |
| 3 | 1       | 2   | 0    |
| 4 | 1       | 1   | 1    |
| 5 | 2       | 1   | 0    |
| 6 | 2       | 2   | 1    |
