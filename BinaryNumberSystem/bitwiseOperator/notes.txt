Check if a Number is a Power of 2 (Bitwise)
=========================================

Concept:
A number is a power of 2 if it has exactly one set bit (1) in its binary representation.

Examples:
1  = 0001
2  = 0010
4  = 0100
8  = 1000
16 = 10000

Observation:
For every power of 2,

n & (n - 1) = 0

Example 1:
n = 8

    8 = 1000
    7 = 0111
-------------
8 & 7 = 0000

Hence, 8 is a power of 2.

Example 2:
n = 10

    10 = 1010
     9 = 1001
--------------
10 & 9 = 1000

Result is not 0, so 10 is NOT a power of 2.

Why do we check n > 0?

For n = 0:

0 & (-1) = 0

This would incorrectly return true.
Therefore, always check that n > 0.

Condition:

if (n > 0 && (n & (n - 1)) == 0)

Time Complexity: O(1)
Space Complexity: O(1)

-----------------------------------------
Code
-----------------------------------------

#include <iostream>
using namespace std;

bool isPowerOfTwo(int n) {
    return (n > 0 && (n & (n - 1)) == 0);
}

int main() {
    int n = 32;

    if (isPowerOfTwo(n))
        cout << "Power of 2";
    else
        cout << "Not a Power of 2";

    return 0;
}
